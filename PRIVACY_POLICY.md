# Privacy Policy for the Discord Bot "Tournament Assistant"

_Last updated: 02/25/2026_

## 1. Introduction
This Privacy Policy explains how the Discord bot **Tournament Assistant** ("Bot") handles data.  
The Bot is operated as a hobby project and does not collect personal data beyond what is required for functionality.

The Bot’s server infrastructure is hosted in **Germany (DE)**.  
All stored data remains on servers located within German territory.

---

## 2. Data Collected by the Bot
The Bot may process the following data:

### 2.1 Discord Data
- Server ID  
- Channel IDs  
- Role IDs  
- User IDs (for tournament or penalty features)  
- Messages sent to the Bot (commands)

The Bot does **not** store message content unless explicitly required for a feature (e.g., logging a penalty reason).

### 2.2 Tournament Data
- Match information  
- Penalty points  
- Team or player identifiers  
- Configuration settings for automation features

### 2.3 Subscription Data
If subscriptions are used, payment processing is handled by **Stripe**.  
The Bot operator does **not** receive or store payment information.

---

## 3. How Data Is Used
Data is used exclusively to:

- Provide Bot functionality  
- Manage tournaments  
- Execute automation features  
- Maintain penalty point systems  
- Ensure fair use and prevent abuse

No data is sold, shared, or used for advertising.

---

## 4. Data Storage
- Data is stored only as long as necessary for Bot functionality.  
- Data may be deleted automatically (e.g., decaying penalty points, deletion of an Organizer using a command).  
- Organizers may request deletion of server-related data.

All stored data remains on servers located in **Germany**.

---

## 5. Data Sharing
Data is **not** shared with third parties except:

- Discord (as part of normal bot operation)  
- Stripe (for subscription payments)

No other sharing occurs.

---

## 6. User Rights
Organizers may request:

- Data deletion  
- Data export (if technically feasible)  
- Removal of the Bot from their server

Removing the Bot automatically stops all data collection.

---

## 7. Security
Reasonable technical measures are used to protect stored data.  
However, no system can guarantee absolute security.

---

## 8. Changes to This Policy
This Privacy Policy may be updated at any time.  
Continued use of the Bot constitutes acceptance of updated terms.
